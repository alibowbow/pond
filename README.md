# 달못 · Dalmot

달이 머무는 연못. 비단잉어가 노니는 한국 정원 연못을 브라우저에서 실시간으로 그리는 작품이에요.
이름은 신라 궁궐 연못 월지(月池, 달못)에서 따왔어요.

`koi-pond.html` 한 파일 안에 정원의 모든 것이 들어 있어요. 지형, 돌, 나무, 물, 잉어, 소리까지 페이지가 열릴 때 코드로 만들어지고,
밖에서 불러오는 것은 three.js, dat.gui, 그리고 한글 글꼴(고운바탕, 고운돋움)뿐이에요.

## 지금 할 수 있는 것

- 비단잉어 스무 마리에게 **먹이 주기**(E)와 **쓰다듬기**(G)
- **영상 투어**, 자유 이동, 걷기, 잉어 따라가기 카메라(C, K)
- **날씨와 계절**: 맑음, 비, 가을, 겨울, 그리고 청사초롱이 켜지는 **달밤**(T)
- 물을 누르면 물결이 일고, 개구리를 누르면 뛰어올라요
- 휴대폰에서는 왼쪽 스틱으로 걷고 오른쪽 스틱으로 둘러봐요

| 키 | 하는 일 | | 키 | 하는 일 |
|---|---|---|---|---|
| `C` | 카메라 모드 | | `E` | 먹이 주기 |
| `P` | 장면 멈춤 | | `G` | 잉어 쓰다듬기 |

## 한국 정원이 되기까지

달못은 네 단계를 거쳐 한국 정원이 되었어요.

1. ✅ 이름, 한글 화면, 먹빛 유리와 청록 포인트, 오방색 띠, 한글 자막
2. ✅ 단청을 입힌 육모정, 돌 홍예교, 팔각석등과 사각석등
3. ✅ 네모난 연못과 둥근 섬(방지원도), 섬 위의 소나무, 장대석 호안과 돌로 된 관어대
4. ✅ 달밤(달과 별, 청사초롱, 반딧불이, 풀벌레 소리), 정자 처마의 풍경, 달못만의 영상 투어

## 실행하기

`koi-pond.html`을 브라우저로 바로 열어도 되고, 로컬 서버로 열면 더 안정적이에요.

```bash
python3 -m http.server 8765
# http://localhost:8765/ 로 열기
```

`?bench`를 붙여 열면 이 기기에서 높음과 낮음 화질의 프레임을 재서 보여 줘요.

## 개발 도구

`tools/`에는 헤드리스 Chromium으로 장면을 찍고 재는 스크립트가 있어요(`tools/verify.mjs`, `tools/shots.mjs`, `tools/ui.mjs` 등).
소프트웨어 렌더러에서 돌기 때문에 한 번 실행에 10분 넘게 걸릴 수 있어요.
